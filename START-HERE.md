### **PHASE 1, WEEK 1: Python Setup (THIS WEEK)**

#### Step 1: Install Python (30 minutes)
```powershell
# 1. Download Python from https://www.python.org/downloads/
# 2. Run installer
# 3. CHECK "Add Python to PATH"
# 4. Click "Install Now"

# Verify installation:
python --version
```

#### Step 2: Install VSCode (10 minutes)
```
Download from: https://code.visualstudio.com/
1. Install VSCode
2. Open VSCode
3. Go to Extensions (Ctrl+Shift+X)
4. Search "Python" by Microsoft
5. Click Install
```

#### Step 3: Create Project Folder
```powershell
cd Desktop
mkdir pbc-platform-engineer
cd pbc-platform-engineer
```

#### Step 4: Create Virtual Environment
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```
You should see: `(venv) PS C:\...>`

#### Step 5: Run Week 1 Exercises
```powershell
# Copy week1-syntax.py to your project
python week1-syntax.py
```

#### Step 6: Try the Interactive Tasks
